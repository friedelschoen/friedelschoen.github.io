# CV-pagina van Friedel Schön

Een statische, semantische CV-pagina zonder framework of buildstap.

## Lokaal bekijken

Open `index.html` rechtstreeks in een browser of start een eenvoudige webserver:

```sh
python3 -m http.server
```

## Opbouw

- `index.html`: inhoud en semantische structuur
- `assets/style.css`: responsive ontwerp en printweergave
- `assets/toggle-dark.js`: optionele themawisselaar
- `assets/friedel.jpg`: profielfoto

De pagina werkt ook zonder JavaScript. JavaScript is uitsluitend nodig voor het handmatig wisselen van thema.
